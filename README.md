# Clínica API REST

Evaluación Integradora — Módulo 3  
Diplomado Full Stack

API REST desarrollada con Node.js, Express, MongoDB y Mongoose para la gestión de médicos y pacientes de una clínica.

## Tecnologías

- Node.js
- Express
- MongoDB
- Mongoose
- JSON Web Token
- bcryptjs
- CORS

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/OGRodrigo/IPPS-DIPLOMADO-CURSO3-V2-CLINICA.git
```

Entrar al proyecto:

```bash
cd IPPS-DIPLOMADO-CURSO3-V2-CLINICA
```

Instalar las dependencias:

```bash
yarn
```

## Variables de entorno

Crear un archivo `.env` en la raíz del proyecto.

Ejemplo:

```env
MONGODB_URI=mongodb://127.0.0.1:27017/clinica
```

El repositorio incluye un archivo `.env.example` como referencia.

## Ejecutar el proyecto

```bash
yarn dev
```

El servidor se ejecuta en:

```text
http://localhost:3001
```
